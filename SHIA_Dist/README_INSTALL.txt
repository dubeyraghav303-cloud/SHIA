SHIA (Self-Healing Infrastructure Agent) - Installation Guide

1. Setup Required Environments
   Before running the SHIA engine, you must populate your `shia_config.json` with the required authorization keys:
   - "gemini_api_key": Your Google Gemini API Key.
   - "supabase_url": Your Supabase project REST URL.
   - "supabase_key": Your Supabase anon/service_role key.

2. Run the Engine
   Open your terminal in this directory and execute:
   ./shia_engine

For further documentation, refer to the SHIA GitHub repository.
